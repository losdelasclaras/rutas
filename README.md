# Los de las Claras · Rutas de montaña

App de las rutas del blog [Los de las Claras](https://losdelasclaras.blogspot.com): Cordillera Cantábrica, Pirineos, Alpes y Dolomitas.

Ábrela en el móvil en **https://losdelasclaras.github.io/rutas/** y elige «Instalar» (Android) o «Compartir → Añadir a pantalla de inicio» (iPhone).
